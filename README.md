# Countdown Timer

A Python-made countdown timer.

This script counts down from a user-specified number of seconds and prints each remaining second until it reaches zero. It is useful for timing activities, reminders, or simple time-based programs.

## How It Works
1. The user enters the countdown duration in seconds
2. The program checks whether the number is greater than zero
3. It counts down from the entered value to 1
4. Each second is printed on the screen
5. When the countdown ends, it displays: “Time’s up!”

## Features
- Takes user input for duration
- Uses a loop to count down second by second
- Displays a message when the time is finished
- Validates input to ensure the duration is greater than zero

## How To Run
1. Make sure you have Python installed
2. Save the script
3. Run it with:
   python `timer.py`

## Example
Enter countdown duration in seconds: 5

5...  
4...  
3...  
2...  
1...  
Time’s up!
